USING THE VIEWER

Help

Your banking files stay read-only. Settings change how the viewer reads and displays them. This guide is included with the app and works offline.

What each source setting does
  • Server name: the label shown in the source selector and account list. Include the mod name when one server has several banking sources.
  • Absolute banking directory: the full path to the folder containing player account JSON files, on the computer running the viewer. Select the account folder itself; subfolders are not searched.
  • Admin log directory: an optional folder containing this server’s ADM logs, used to find names for Expansion accounts. Leave blank for automatic lookup in recognised layouts. A supplied path replaces automatic lookup.
  • Enabled: allows startup, manual and scheduled scans. Disabled sources are excluded from All servers; selecting one may still show its cached accounts.
  • Add server: adds another banking source. Several sources can belong to the same physical server.
  • Remove configuration: removes the source from the viewer when you save. It does not delete banking files.
  • Save settings: saves your changes and refreshes enabled sources. Cancel discards unsaved changes. Changing either folder clears that source’s cached results; renaming keeps them.
Which banking folder to choose

Paths below are relative to your server’s profiles directory:

  • Banking: Banking/PlayerDataBase
  • KR Banking: KR_BANKING/PlayerDataBase
  • DayZ-Banking / DC Banking: DC_Banking/PlayerDatabase
  • DayZ Expansion: ExpansionMod/ATM

Formats are detected from file contents. Banking and KR Banking share fields, so the viewer labels them as compatible rather than claiming which mod created them. Settings-editor exports, KR clan accounts and Expansion shared party accounts are outside this player-account view.

Two banking mods on one server
  1. Add a source named Chernarus — Expansion pointing at its ATM folder.
  2. Add another named Chernarus — KR Banking pointing at its player database folder.
  3. Choose either under Banking source to see its accounts and totals separately.

All servers combines enabled sources and keeps accounts separate. Adding the same folder twice counts its balances twice. Totals add raw currency amounts without exchange rates; view sources separately if currencies differ or records mirror the same funds.

Expansion names, IDs and admin logs

Expansion ATM files contain a DayZ player ID and balance, without a name or Steam64 ID. The viewer matches that exact DayZ ID to local ADM entries to find a last observed name. Unmatched accounts show Unnamed player. Names can change; they are not used to establish identity.

For an ExpansionMod/ATM source, automatic lookup checks its profiles folder and existing log_storage inside it. When that folder is named profiles or profile, it also checks the sibling server-root log_storage. Set Admin log directory for other layouts.

Admin logging must already be enabled on the server with -adminlog. Lookup searches up to 20 ADM files, newest modification time first, reading at most the last 4 MiB per file and 32 MiB per refresh. Missing or limited log reads are shown separately from banking errors.

No Steam-ID conversion library is included. ADM name matching does not recover Steam64 IDs. Unique player ID counts keep DayZ and Steam64 IDs separate, so one person may count twice across those systems.

Refresh times, connection and updates
  • Daily scan times: comma-separated 24-hour times, such as 06:00, 18:00, using the viewer computer’s timezone shown in Settings. Blank turns off scheduled scans; startup, Settings saves and manual refresh still scan enabled sources. Missed scans are not replayed.
  • Refresh: reads the selected source, or all enabled sources when All servers is selected. The viewer must be running for scheduled refreshes. Dashboard polling only reads cached results.
  • Listen address: where the dashboard is served. Keep 127.0.0.1:20784 for access from this computer. Changes require an app restart; an occupied port may cause the viewer to use a nearby port. Check the desktop window for the actual address. There is no built-in login or TLS; LAN access needs appropriate network protection.
  • Check for updates: contacts GitHub only when pressed. It offers a release link if an update is available, without downloading or installing it.
Missing accounts, permissions and cached results

Check the folder path and scan information first. Only direct JSON account files are read; links and invalid files are skipped. A partial scan shows valid accounts with incomplete totals. If the whole scan fails, previous results stay visible with a warning. An empty account folder produces an empty result.

The viewer needs read and folder-traversal permission for banking files and any logs. Desktop mode runs as you. Optional unattended mode uses its service account, which may have different access. Source files do not need write permission.

Only stored bank balances contribute to rankings. Bonus currency, paycheck bonuses and DC account capacity bonuses are shown separately in account details. Search filters the list, while summary cards still cover the selected source. Cached results and log-derived names are held in memory and reset when the app exits.
